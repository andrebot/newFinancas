View Report

Ad-hoc report types deferred to v2 (OQ-71) — the /reports/:reportType resource itself is v1, serving the fixed types month-overview, investments-overview, payouts. GET /reports/:reportType — FR-6.2/6.3/6.6. One generic use case standing in for spend-by-category, income-vs-expense, and account-balance-by-month — the same computation shape, different parameters.

sequenceDiagram
    actor User
    participant API as Hono route
    participant IM as InsightsManager
    participant RE as ReportingEngine

    User->>API: GET /reports/:reportType?dateRange=...&accountId=...
    API->>IM: getReport(actor, reportType, params)
    alt reportType unknown or dateRange malformed
        IM-->>API: BadRequest
        API-->>User: 400 report.unknown_type_or_range
    else valid
        IM->>RE: generate(reportType, params, actor)
        RE->>ATA: query(actor, dateRange, filters)
        ATA-->>RE: rows
        RE->>CTA: query(actor, dateRange, filters)
        CTA-->>RE: rows
        Note over RE: income-vs-expense excludes transfers via the persisted
effect column (FR-3.6) — not recomputed from kind each time
        RE-->>IM: report data
        IM-->>API: report
        API-->>User: 200 OK {report data}
    end
