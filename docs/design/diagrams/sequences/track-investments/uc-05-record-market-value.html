Record Market Value

POST /holdings/:holdingId/valuation-snapshots — FR-5.2/OQ-56. Manual Valuation Snapshot of a market-priced Holding (stock, FII, fund, other).

sequenceDiagram
    actor User
    participant API as Hono route
    participant AM as AccountManager
    participant AZ as AuthorizationUtility
    participant VU as ValidationUtility
    participant IHA as InvestmentHoldingAccessor
    participant VSA as ValuationSnapshotAccessor
    participant LOG as LoggingUtility

    User->>API: POST /holdings/:holdingId/valuation-snapshots {value, asOf}
    API->>AM: recordMarketValue(actor, holdingId, input)
    AM->>AZ: canWrite(actor, holdingId)?
    alt not authorized
        AZ-->>AM: denied
        AM-->>API: Forbidden
        API-->>User: 403 auth.forbidden
    else authorized
        AZ-->>AM: allowed
        AM->>VU: check(input)
        AM->>IHA: get(holdingId)
        alt Holding is a fixed-term instrument (OQ-51)
            IHA-->>AM: assetType = CDB / Tesouro / ...
            AM-->>API: Conflict
            API-->>User: 409 holding.not_market_priced
        else market-priced
            IHA-->>AM: ok
            AM->>VSA: insertManual(holdingId, value, asOf)
        end
        AM-->>LOG: logActivity(correlationId, actor, "RecordMarketValue")
        AM-->>LOG: recordAudit(actor, "ValuationSnapshot", snapshotId)
        AM-->>API: done
        API-->>User: 201 Created {snapshotId}
    end
  • Fixed-term Holdings have no snapshots (value = cost basis until redemption, OQ-51).
  • Net worth and goal progress read “latest snapshot at or before month end” on demand — nothing to recompute here.
  • See FR-5.2, OQ-51, OQ-56, OQ-83.
