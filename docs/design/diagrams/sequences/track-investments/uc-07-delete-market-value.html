Delete Market Value

DELETE /households/:householdId/holdings/:holdingId/valuation-snapshots/:snapshotId — FR-5.2/OQ-56. Manual Valuation Snapshot of a market-priced Holding (stock, FII, fund, other).

sequenceDiagram
    actor User
    participant API as Hono route

    participant AU as AuthorizationUtility

    User->>API: DELETE /households/:householdId/holdings/:holdingId/valuation-snapshots/:snapshotId 
    API->>AM: deleteMarketValue(context, householdId, holdingId, snapshotId)
    AM->>IHA: findById(householdId, holdingId)
    IHA-->>AM: holding (or none)
    AM->>AA: findById(householdId, holding.accountId)
    AA-->>AM: its Account
    AM->>AU: authorize(actor, householdId, {data.edit, account.visibility, account.ownerUserId})
    alt not a member
        AM-->>API: 404 household.not_found
    else missing, or in someone else's personal Account
        AM-->>API: 404 holding.not_found
    else role may not maintain (a Member may on a shared Account they created)
        AM-->>API: 403 auth.forbidden
    else allowed
        alt Holding archived
            AM-->>API: 409 holding.archived
        else fixed-term (OQ-51)
            AM-->>API: 409 holding.not_market_priced
        else market-priced
                AM->>VSA: deleteManual(holdingId, snapshotId)
                alt not this Holding's snapshot
                    VSA-->>AM: not_found
                    AM-->>API: 404 snapshot.not_found
                else automatic (source = transaction)
                    VSA-->>AM: automatic
                    AM-->>API: 409 snapshot.automatic_not_editable
                else written
                    VSA-->>AM: done
                    AM-->>LOG: audit DeleteMarketValue
                    API-->>User: 204 No Content
                end
        end
    end
  • If it was the latest, the previous snapshot becomes the current value.
  • As built (OQ-178): access is the Holding's Account's (data.edit for all three writes); an archived Holding takes no new value; a date after today is refused on the field (date.max), as everywhere else (OQ-165).
  • Net worth and goal progress read “latest snapshot at or before month end” on demand — nothing to recompute here.
  • See FR-5.2, OQ-51, OQ-56, OQ-83, OQ-178.
