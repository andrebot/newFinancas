Create Category

POST /households/:householdId/categories — FR-10.1. A custom Category supplementing the predefined default set every household is seeded with (VBD doc §3.1b).

sequenceDiagram
    actor User
    participant API as Hono route
    participant AM as AccountManager
    participant AZ as AuthorizationUtility
    participant VU as ValidationUtility
    participant CA as CategoryAccessor
    participant LOG as LoggingUtility

    User->>API: POST /households/:householdId/categories {name, icon, color}
    Note over API: contract check: icon and colour are enums
(CategoryIcon, CategoryColor — OQ-174) → 422 before the Manager
    API->>AM: createCategory(actor, householdId, {name, icon, color})
    AM->>AZ: authorize(actor.userId, householdId, data.create on shared data, owner none)
    alt not a member
        AZ-->>AM: not_member
        AM-->>API: NotFound
        API-->>User: 404 household.not_found
    else a Viewer
        AZ-->>AM: forbidden
        AM-->>API: Forbidden
        API-->>User: 403 auth.forbidden
    else allowed
        AZ-->>AM: allowed
        AM->>VU: checkFields({name}, {name: nonBlank})
        alt name blank once trimmed
            VU-->>AM: [name: string.min]
            AM-->>API: ValidationError
            API-->>User: 422 validation.failed {details}
        else valid
            VU-->>AM: []
            AM->>CA: insert(householdId, {name trimmed, icon, color})
            Note over CA: refuses an icon/colour outside the in-code sets as a
second line (invalid_icon / invalid_color, OQ-173)
            alt refused
                CA-->>AM: invalid_icon / invalid_color
                AM-->>API: ValidationError
                API-->>User: 422 validation.failed {icon / color: field.invalid_option}
            else inserted
                CA-->>AM: Category (no Subcategories yet)
                AM-->>LOG: log.audit("CreateCategory", Category categoryId)
                AM-->>API: Category
                API-->>User: 201 Created Category
            end
        end
    end
  • No visibility field — Category is pure household-shared taxonomy with no recorded creator, so the permission table reads it as shared data nobody owns (OQ-174): any member but a Viewer may create one; editing and archiving are Owner/Admin (FR-1.7).
  • Oct 2026 review: icon + colour (fixed palette) on every category (FR-10.1, OQ-57). Both are contract enums mirroring @financas/reference, kept equal by a test (OQ-174).
  • OQ-173: the Accessor re-checks icon and colour and returns invalid_icon/invalid_color; the route's 422 normally fires first. Names need not be unique.
