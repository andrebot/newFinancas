Archive Financial Account

POST /households/:householdId/accounts/:accountId/archive — FR-2.4/OQ-34. One-way, no unarchive path; refused while the Account holds an open Holding (OQ-226). Auto-disconnects Open Banking sync if linked (OQ-36) — currently a no-op since that trigger is parked.

  • An archived Account takes no new transactions (FR-2.4, OQ-169 — TransactionManager's check) and can't be edited (409 account.archived, OQ-175).
  • An Account still holding position can't be archived (409 account.holdings_open, OQ-226): its Holdings would keep posting schedule entries into an Account that takes none. A sold-out Holding is already system-archived, so only an open position blocks.
