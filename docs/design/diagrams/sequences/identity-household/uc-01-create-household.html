Create Household

POST /households — FR-1.4. The one Manager↔Manager effect in the whole system (VBD doc §3.1b): seeding default Categories is AccountManager's job, reached only through the Service Bus, never a direct call.

sequenceDiagram
    actor User
    participant API as Hono route
    participant IM as IdentityManager
    participant UA as UserAccessor
    participant HA as HouseholdAccessor
    participant SB as ServiceBusUtility
    participant AM as AccountManager
    participant CA as CategoryAccessor
    participant LOG as LoggingUtility

    User->>API: POST /households {name}
    Note over API: name trimmed and non-blank (contract validation, OQ-116)
    API->>IM: createHousehold(actor, name)
    IM->>UA: findById(actor.userId)
    alt the account is gone
        UA-->>IM: none
        IM-->>API: Unauthorized
        API-->>User: 401 auth.unauthenticated
    else found
    UA-->>IM: creator (language)
    IM->>HA: insert(name, ownerUserId = actor.userId)
    HA-->>IM: household (creator is Owner, one transaction)
    IM->>SB: publish("household.created", {householdId, createdByUserId, language})
    Note over SB: fire-and-forget — AccountManager seeds the default
categories in the creator's language (OQ-117)
    SB-->>AM: subscribe("household.created")
    AM->>CA: seedDefaults(householdId, language)
    CA-->>AM: default Categories created
    IM-->>LOG: log.audit("CreateHousehold", Household householdId)
    IM-->>API: household + role Owner
    API-->>User: 201 Created MyHousehold
    end
  • No IdentityManager → AccountManager edge — the Category-seeding call is entirely on AccountManager's side of the Service Bus subscription; IdentityManager never learns AccountManager or CategoryAccessor exist (VBD doc §3.1b).
  • The event carries the creator and their language ({householdId, createdByUserId, language}, OQ-117): default categories are seeded in the creator's language, and AccountManager must not reach into Identity's data to find it.
  • The Service Bus hop is fire-and-forget from IdentityManager's perspective — the 201 response doesn't wait on Category seeding completing.
  • See docs/architecture/backend/01-vbd-decomposition.md §3.1b and FR-1.4/FR-10.1.
