View Month Overview

GET /reports/month-overview?year=&month= — FR-6.11, FR-6.6, FR-4.3, FR-8.5/OQ-74. A fixed v1 report type of GET /reports/{reportType} (stakeholder: reports will expand later).

  • One currency is shown at a time in the UI ($/R$ switch) — the response carries every currency, never summed (FR-2.2).
