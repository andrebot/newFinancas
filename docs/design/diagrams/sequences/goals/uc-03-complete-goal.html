Complete Goal

POST /households/:householdId/goals/:goalId/complete — FR-8.8. “This goal is completed” — keeps the record intact so historical progress-by-month stays viewable, and is reversible (see Reopen).

sequenceDiagram
    actor User
    participant API as Hono route
    participant AM as AccountManager
    participant AU as AuthorizationUtility
    participant GA as GoalAccessor
    participant LOG as LoggingUtility

    User->>API: POST /households/:householdId/goals/:goalId/complete
    API->>AM: completeGoal(context, householdId, goalId)
    AM->>GA: findById(householdId, goalId)
    GA-->>AM: goal (or none)
    AM->>AU: authorize(actor, householdId, {data.edit, goal.visibility, goal.ownerUserId})
    alt not a member
        AM-->>API: 404 household.not_found
    else missing, or someone else's personal Goal
        AM-->>API: 404 goal.not_found
    else role may not edit (a Member may on a shared one they created)
        AM-->>API: 403 auth.forbidden
    else allowed
        alt already completed
            AM-->>API: nothing to write, unaudited (OQ-177)
            API-->>User: 204 No Content
        else
            AM->>GA: complete(householdId, goalId)
            Note over GA: sets completed_at — unlike every other archive in this
project, this one CAN be undone (FR-8.9)
            alt deleted meanwhile
                GA-->>AM: false
                AM-->>API: 404 goal.not_found
            else written
                GA-->>AM: true
                AM-->>LOG: audit CompleteGoal
                API-->>User: 204 No Content
            end
        end
    end
  • Distinct from Delete (UC-05): complete means “done,” delete means “no longer makes sense” — OQ-47's “third lifecycle pattern,” the only entity in this project with both a hard delete and a reversible completion.
  • Corrected (OQ-177): completing is a data.edit on the Goal; completing a completed Goal is a 204 that writes and audits nothing.
  • See FR-8.8, OQ-47, OQ-177.
