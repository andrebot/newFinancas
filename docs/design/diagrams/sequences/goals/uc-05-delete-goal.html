Delete Goal

DELETE /households/:householdId/goals/:goalId — FR-8.6. Hard delete, no history kept — “this goal no longer makes sense.” The underlying Investment Holdings are never deleted.

sequenceDiagram
    actor User
    participant API as Hono route
    participant AM as AccountManager
    participant AU as AuthorizationUtility
    participant GA as GoalAccessor
    participant LOG as LoggingUtility

    User->>API: DELETE /households/:householdId/goals/:goalId
    API->>AM: deleteGoal(context, householdId, goalId)
    AM->>GA: findById(householdId, goalId)
    GA-->>AM: goal (or none)
    AM->>AU: authorize(actor, householdId, {data.delete, goal.visibility, goal.ownerUserId})
    alt not a member
        AM-->>API: 404 household.not_found
    else missing, or someone else's personal Goal
        AM-->>API: 404 goal.not_found
    else role may not delete (a Member may on a shared one they created)
        AM-->>API: 403 auth.forbidden
    else allowed
        AM->>GA: delete(householdId, goalId)
        Note over GA: hard delete, no history — goal_allocations rows
cascade away, but the Investment Holdings they referenced
are completely untouched (FR-8.6)
        alt deleted meanwhile
            GA-->>AM: false
            AM-->>API: 404 goal.not_found
        else deleted
            GA-->>AM: true
            AM-->>LOG: audit DeleteGoal
            API-->>User: 204 No Content
        end
    end
  • Contrast with Complete (UC-03): this is deliberately unrecoverable, for the case where the Goal itself was a mistake, not merely completed. Deleting it again is 404: nothing is left.
