Edit Goal

PATCH /households/:householdId/goals/:goalId — FR-8.1. Name, target, target currency and due date only — never the visibility, never the allocations (OQ-48).

sequenceDiagram
    actor User
    participant API as Hono route
    participant AM as AccountManager
    participant AU as AuthorizationUtility
    participant VU as ValidationUtility
    participant GA as GoalAccessor
    participant LOG as LoggingUtility

    User->>API: PATCH /households/:householdId/goals/:goalId {name?, targetAmount?, targetCurrency?, dueDate?}
    Note over API: contract check first: targetAmount ≥ 1, currency, dueDate a date
    API->>AM: editGoal(context, householdId, goalId, edit)
    AM->>GA: findById(householdId, goalId)
    GA-->>AM: goal (or none)
    AM->>AU: authorize(actor, householdId, {data.edit, goal.visibility, goal.ownerUserId})
    alt not a member
        AM-->>API: 404 household.not_found
    else missing, or someone else's personal Goal
        AM-->>API: 404 goal.not_found
    else role may not edit (a Member may on a shared one they created)
        AM-->>API: 403 auth.forbidden
    else allowed
        AM->>VU: checkFields({name: nonBlank})
        alt blank name
            AM-->>API: 422 validation.failed {name}
        else nothing to change
            AM-->>API: the Goal as read, unaudited
            API-->>User: 200 OK {goal}
        else changes
            AM->>GA: update(householdId, goalId, changes)
            alt deleted meanwhile
                GA-->>AM: none
                AM-->>API: 404 goal.not_found
            else updated
                GA-->>AM: goal
                AM-->>LOG: audit EditGoal
                AM-->>API: goal
                API-->>User: 200 OK {goal}
            end
        end
    end
  • This endpoint has no allocations field at all — contrast with Edit Investment Holding (docs/design/diagrams/sequences/track-investments/uc-02-edit-holding.html), which is where allocation changes actually happen.
  • A completed Goal can be edited too (OQ-177): FR-8.9 closes only new funding to it (goal.completed, on Edit Holding). Changing the target currency is allowed: progress is derived on read, nothing stored follows it (OQ-168).
  • See FR-8.1, OQ-48, OQ-177.
