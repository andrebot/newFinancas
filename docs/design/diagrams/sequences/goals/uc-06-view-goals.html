View Goals

GET /households/:householdId/goal-progress?status=active|completed, GET /households/:householdId/goals/:goalId/progress?year=&month= — FR-8.5/8.7/FR-9. Progress per currency, computed on read — the frontend blends currencies with the user's on-the-fly rate (nothing stored). As built in M4 (OQ-208).

  • FX stays in the browser (FR-9, OQ-49): “1 USD = x BRL” is typed on the goal card and only blends the returned per-currency contributions for display.
  • Reshaped read → InsightsManager + ReportingEngine (read-ownership rule), built with M4. OQ-177: moved to its own route — GET /households/:householdId/goals is AccountManager's plain list of definitions (OQ-174); GET …/goals/:goalId/allocations was dropped, as fundedBy here covers it. GET /households/:householdId/goals/:goalId/progress stays for the by-month history (FR-8.7).
  • OQ-206: a fixed-term Holding's value on a date is its trades' cost basis by then (the by-month history uses the month's end); funding in an Account the viewer can't see counts, with holdingId and name null, so every member sees a shared Goal's same total.
