Export Audit Log

GET /households/:householdId/audit-log/export?startDate=&endDate= — FR-7.2/OQ-46. Owner/Admin only. This is the Audit Log's ONLY access method in v1 — there is no in-app browsable table anywhere in this API. As built in task 139 (OQ-243): both days required, the end not before the start.

  • No logActivity/recordAudit here — matches InsightsManager's established pattern of reads never triggering the audit write path (FR-7.1 scopes it to financial/household-data mutations).
  • AuditLogAccessor itself never grants UPDATE/DELETE to the application role at the database level — append-only is enforced by privilege, not by this call path's own discipline.
  • The app (task 139, OQ-243): the drawer's “Export audit log” (Owners and Admins only) opens Review Insights' dialog — Last 30 days, Last 90 days, This year or Custom — which checks the same two rules before asking, then saves the CSV under the name the API gave it.
