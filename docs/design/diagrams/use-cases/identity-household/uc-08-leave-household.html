UC-8: Leave Household

Use case 8 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-1). Traces to FR-1.11. Self-initiated — any member, including the Owner. See UC-7 for the Owner/Admin-initiated removal of someone else. High-level activity view only — no component names or API details yet.

Where FR-1.18 actually lives: this is the one use case (besides Delete Account, UC-10) where the Owner-succession invariant is exercised — the longest-tenured remaining Admin (then Member, then Viewer) is auto-promoted, or the household is dissolved if the departing Owner was its only member.
