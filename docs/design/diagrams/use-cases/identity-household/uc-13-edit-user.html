Preferences added (FR-1.21, Oct 2026 review): per user, not per household.

No role/permission check: a user always edits only their own profile — there's no actor-vs-target distinction here, unlike the household-membership use cases.

Password and MFA are separate use cases (UC-19 Change Password, UC-20/21 for MFA) — not folded into generic profile editing, since they carry distinct security consequences (session invalidation, re-authentication).
