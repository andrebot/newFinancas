UC-12: Delete User

Use case 12 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-2). Traces to FR-1.17 — self-service hard delete supporting GDPR/LGPD right-to-erasure (NFR-COMP-4). High-level activity view only — no component names or API details yet.

Ties together the GDPR/LGPD decisions (OQ-25, OQ-27, OQ-28, FR-1.18): succession runs per-household (a user can own more than one, FR-1.8), shared contributions are anonymized not deleted, and only truly personal data is hard-deleted. The Audit Log entry for this action (and every prior action by this user) needs no cleanup — it never stored anything beyond actor ID, timestamp, action, and entity ID (FR-7.1).
