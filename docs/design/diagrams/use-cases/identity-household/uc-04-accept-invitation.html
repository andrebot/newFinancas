Entry points (Oct 2026 review): the notification inbox (accept inline), Profile → Invitations, or the household switcher's pending invitations.

Precondition: the invitee is always an existing, registered user — invitations (UC-3) can only target an existing account (see FR-1.19 / OQ-26). There is no "invite a non-user, they sign up through the invite" path in this design, so Create User (UC-9) is never a step inside this use case.
