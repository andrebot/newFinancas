UC-21: List My Households

Use case 21 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-1). Traces to FR-1.8 (OQ-60). High-level activity view only — no component names or API details yet. Added in the Oct 2026 use case review (docs/architecture/05-use-case-review-2026-10.md).

Switching is not a backend use case: the frontend keeps the active household and sends it with every request; RBAC (NFR-SEC-6) checks membership on each call.

'Create household' in the same menu goes to Create Household (UC-1).
