UC-15: Logout

Use case 15 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-2). Traces to FR-1.9 — terminates the current session only. High-level activity view only — no component names or API details yet.

Client-side cleanup is not optional (OQ-30): auth is confirmed JWT/OAuth2-based. Since a JWT access token is stateless and can't be revoked before it expires, the frontend clearing its own locally-held token is the only immediate way to end the session on this device — the backend side of logout is really about revoking the underlying refresh token (see UC-17, Revoke Session).
