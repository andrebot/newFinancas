UC-14: Login

Use case 14 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-2). Traces to FR-1.2 — password plus mandatory MFA. High-level activity view only — no component names or API details yet. Two backend round-trips, shown as two submit/receive pairs.

Security-sensitive, feeds the Audit Log (NFR-OBS-4): unlike most use cases in this set, a login attempt is routed to both the Application Log and the Audit Log — login is one of the explicitly named security-sensitive events (alongside MFA challenge, permission change, Open Banking connect/disconnect).
