UC-19: Change Password

Use case 19 of 21 in the Identity & Household set (docs/requirements/01-core-use-cases.md, CUC-2). Traces to FR-1.14. Authenticated flow — see UC-18 for the unauthenticated "forgot password" path. High-level activity view only — no component names or API details yet.

    FE4 -- request --> BE1

Password minimum 12 characters (NFR-SEC-4, OQ-64).

Difference from UC-18 (Reset): this flow keeps the current session alive — identity is already proven by the existing session plus the current password, unlike a reset token which proves only email access, so UC-18 invalidates everything including the session that completed it.
