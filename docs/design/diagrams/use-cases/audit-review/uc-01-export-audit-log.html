UC-1: Export Audit Log

The single use case in the Audit & Review Activity set (docs/requirements/01-core-use-cases.md, CUC-9). Traces to FR-7.2. Owner/Admin only, export-only — no in-app browsable table (OQ-46). High-level activity view only — no component names or API details yet.

Export-only (OQ-46): no in-app browsable table — same shape as Export Transactions to CSV (CUC-8, UC-4).

Entries are IDs + action only (FR-7.1): the exported CSV contains actor ID, timestamp, action, entity type, and entity ID — no field-level before/after values or other PII.

Own active sessions belong to CUC-2, not here: reviewing/revoking your own sessions (originally part of this CUC's description) is fully covered by CUC-2's View/Revoke Session use cases (UC-16/UC-17) — not duplicated in this set.
