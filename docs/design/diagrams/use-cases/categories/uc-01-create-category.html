UC-1: Create Category

Use case 1 of 3 in the Categories set (docs/requirements/02-functional-requirements.md, FR-10.1 — supports CUC-4/CUC-5, no CUC number of its own). Create pattern, optional inline Subcategories, same shape as Create Financial Account. High-level activity view only — no component names or API details yet.

Icon + colour (FR-10.1, OQ-57, Oct 2026 review): they identify the category everywhere it appears.

Household-scoped, not personal (FR-10.1): the default set ships with the household (seeded at Create Household time, see the Identity & Household set's UC-1) and this use case lets the household supplement it with custom categories.

Same shape as Create Financial Account: a container (Category) with optional child items (Subcategories) added inline at creation — same pattern as accounts optionally getting Credit Cards attached inline.
