UC-3: Archive Category or Subcategory

Use case 3 of 3 in the Categories set (FR-10.3/FR-10.4). Lifecycle Transition, one-way, same pattern as Accounts/Holdings — archiving a Category cascades to its Subcategories. High-level activity view only — no component names or API details yet.

Archiving a Subcategory alone does not affect its parent Category or siblings (FR-10.4): the cascade only flows downward (Category → its Subcategories), never upward or sideways. Existing categorizations and Budget targets that reference an archived Category/Subcategory remain intact and meaningful, same as the Account/Holding archive pattern.
