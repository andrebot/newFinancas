Narrowed in this review: a Holding's position is read-only (it changes only through its transactions), and its market value has its own use cases (Record / Edit / Delete Market Value). What's left to edit on the Holding itself is goal allocation.

Direction of control (OQ-48): allocations are edited from the Holding, never from the Goal.
