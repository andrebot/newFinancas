UC-2: Edit Financial Account (incl. Credit Cards)

Use case 2 of 3 in the Manage Financial Accounts set (Open Banking Connect / Disconnect / Sync deferred — OQ-69) (docs/requirements/01-core-use-cases.md, CUC-3). Traces to FR-2.3 (visibility) and FR-2.7/FR-2.9 (Credit Card attach/edit/remove — folded in here, see OQ-35). High-level activity view only — no component names or API details yet.

One combined form, one submit (OQ-35): account field edits and any credit card add/edit/remove all travel together in a single request — there is no separate "attach card" or "remove card" action with its own round-trip.

Not editable here: account type and currency (OQ-32) — immutable after creation (UC-1).
