UC-6: View Goals

Use case 6 of 6 in the Goals set (docs/requirements/01-core-use-cases.md, CUC-10). Traces to FR-8.5, FR-8.7, FR-9. High-level activity view only — no component names or API details yet. Added in the Oct 2026 use case review (docs/architecture/05-use-case-review-2026-10.md). 

flowchart LR

    subgraph BE["Backend"]
        direction TB
        BE1["Receive request"]
        BE2["Fetch visible goals (active or completed)"]
        BE3["For each goal: per allocated Holding,
contribution = latest valuation × % —
in the Holding's own currency"]
        BE4["Group contributions by currency"]
        BE5["Send response"]
        BE1 --> BE2 --> BE3 --> BE4 --> BE5

    FE3 -- request --> BE1
    BE5 -- response --> FE4

Why a use case: progress is computed on read from the latest valuation snapshots, never stored (FR-8.5) — this is the read path the Goals page, the Transactions overview and the Dashboard all share.

FX stays client-side (FR-9, OQ-49): the backend returns contributions per currency; the exchange-rate input on the goal view only blends them for display.
