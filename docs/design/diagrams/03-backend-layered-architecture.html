Column alignment is informative, not arbitrary: each Accessor column sits under the Manager (and, where one exists, the Engine) that owns it — e.g. InvestmentProductEngine sits under TransactionManager's column because that's who calls it, never AccountManager. The Account column is visibly the tallest (13 Accessors, 5 parked — Round 9 adds IndexRateAccessor) — that's the honest shape of AccountManager's scope (Financial Accounts, Credit Cards, Categories, Budgets, Investment Holdings, Goals, Index Rates, Portfolio, Open Banking config), not a layout artifact.

No wiring shown deliberately. This page answers "what exists, and in which tier" — the call-chain-by-use-case pass (next) answers "who actually calls whom, for this specific flow," which is where smells like Manager sprawl, hidden Manager↔Manager coupling, or Accessor over-fan-out would actually show up.
